========================================
 3D PORTFOLIO WEBSITE — IMAGE CUSTOMIZATION GUIDE
========================================

This website is designed to be easily customized. Simply replace
the placeholder images in each folder below with your own content.
No code changes are needed — just swap the files!

========================================
 FOLDER: profile/
========================================
Put your personal profile photo here.

  profile.png    — Your headshot/avatar (square, 300x300+ recommended)
                   Used in: About Me modal, hero section

========================================
 FOLDER: hero/
========================================
Background and hero section images.

  bg.png           — Hero section decorative background
                     (1920x1080 recommended, can be abstract/tech)

========================================
 FOLDER: projects/
========================================
Screenshots or images for your portfolio projects.

  project1.png     — Your first/main project screenshot (800x600+)
  project2.png     — Your second project screenshot (800x600+)
  project3.png     — Your third project screenshot (800x600+)

========================================
 FOLDER: experience/
========================================
Images for the Research & Professional Experience cards.

  exp1.png         — Image for experience card #1 (Ph.D. / current role)
  exp2.png         — Image for experience card #2 (internship / past role)
  exp3.png         — Image for experience card #3 (research project)
  logo1.png        — Logo for experience #1 (university / company)
  logo2.png        — Logo for experience #2 (company logo)
  logo3.png        — Logo for experience #3 (project/institution logo)

========================================
 FOLDER: skills/
========================================
Icons representing your core abilities/skills.

  seo.png          — Icon for ability #1 (Statistical Rigor / skill 1)
  chat.png         — Icon for ability #2 (Reproducible Research / skill 2)
  time.png         — Icon for ability #3 (Scalable ML Pipelines / skill 3)

========================================
 FOLDER: social/
========================================
Social media and contact icons for the footer and About Me modal.

  linkedin.png     — LinkedIn icon (32x32+)
  email.png        — Email icon (32x32+)  [was: fb.png]
  github.png       — GitHub icon (32x32+) [was: x.png]

========================================
 FOLDER: branding/
========================================
Company/institution logos shown in the logo showcase strip.

  company-1.png    through company-11.png — 11 brand logos
  (140x60+ each, transparent background recommended)

========================================
 FOLDER: tech/
========================================
Technology stack icons (static image versions, currently unused
but kept for future use).

  python.svg       — Python logo
  r-lang.png       — R logo
  pytorch.png      — PyTorch logo
  scikit.png       — scikit-learn logo
  git.svg          — Git logo

========================================
 FOLDER: ui/
========================================
UI elements used across the site.

  arrow-down.svg   — Down arrow icon for CTA buttons
  star.png         — Star icon for testimonial/review cards (16x16+)

========================================
 FOLDER: fav/
========================================
Browser tab icon (favicon).

  fav.png / favicon.ico — Website favicon (32x32 or 64x64)

========================================
 UNUSED IMAGES (can be deleted)
========================================
  arrow-right.svg, client1-6.png, devices.png, gold-star.png,
  jsm-logo.png, person.png, readme*.png, insta.png, menu.svg,
  x.svg, screen.mp4, ideas.svg, concepts.svg, designs.svg,
  code.svg

========================================
 TIPS:
========================================
  - Keep PNG files under 500KB for fast loading
  - Use .png for photos, .svg for logos/icons when possible
  - Images should match the color scheme (dark theme: #0a1628 bg)
  - Test your site after replacing images: npm run dev
  - The 3D models are in the models/ folder (not covered here)
